## ➕ Cómo agrego una práctica o proyecto nuevo

1. Crea una carpeta nueva siguiendo el patrón `practicaN_100033745/` o `proyectoN_100033745/` (por ejemplo `practica4_100033745/` o `proyecto2_100033745/`).
2. Adentro, agrega un archivo llamado exactamente `index.html` (así se publica solo con GitHub Pages).
3. Opcionalmente, agrega `<meta name="description" content="tu descripción">` dentro de ese `index.html` para que aparezca como descripción.
4. Haz commit y push. La GitHub Action se encarga de agregarla sola a este README y al `index.html` de la raíz — no hace falta editarlos a mano.
